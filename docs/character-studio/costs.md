# Character Studio costs

All calls are logged in `docs/art/ledger.json` / `LEDGER.md` (entries 248 onwards). Keys come from
the environment and are never written anywhere.

| What | Service | Price |
| --- | --- | --- |
| Base picture (text to image) | NanoGPT `qwen-image` | free (95 a day in the subscription) |
| One aligned edit (one trait option) | NanoGPT `qwen-image-2.1/edit` | about $0.03 |
| FLUX 3 Klein edit (tested, reframes the picture: not used) | NanoGPT | $0.036 |
| RunPod | — | not used ($0) |

## Per template

A standing template has the following edits:

| Edits | Count |
| --- | --- |
| bald body | 1 |
| hairstyles (4, plus the base's own) | 4 |
| outfit items | 2 |
| expressions | 2 |
| eye colour | 1 |
| **Total** | 10 edits, about $0.30 |

Each further option is one more edit, about $0.03. Colours and body types cost nothing: they
are recolours and cage presets.
