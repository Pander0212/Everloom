# @everloom/script-types

Types for Everloom scripts and extensions. Add `/// <reference types="@everloom/script-types" />` at the top of a script, or list the package in your editor's `types`, to get completion for the `everloom` object and `everloom-extension.json` (`ExtensionManifest`).

See `docs/scripting.md` and `docs/extensions.md` in the Everloom repository.
